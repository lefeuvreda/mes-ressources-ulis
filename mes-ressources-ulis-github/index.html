Mode d’emploi

1. Retrouver une fiche

Sélectionne ton niveau, une discipline, puis ouvre une carte. Utilise la recherche pour trouver un mot-clé.

2. Adapter la lecture

Dans une fiche, A+ agrandit le texte, « Lignes » augmente l’espacement, « Confort » change le fond, et « Écouter » lit le texte à voix haute lorsque l’appareil le permet.

3. Mettre une fiche en favori

Appuie sur l’étoile. Les favoris sont enregistrés uniquement sur cette tablette.

4. Travailler sans connexion

Les fiches publiées sont sauvegardées sur cette tablette après connexion. Lorsque le réseau revient, les nouveautés arrivent automatiquement. Hors ligne, la dernière version sauvegardée reste accessible.

Confidentialité

Cette application ne demande ni nom, ni mot de passe, ni information sur la situation scolaire ou médicale de l’élève. Elle conserve seulement le niveau, les réglages de lecture et les favoris localement sur l’appareil.
